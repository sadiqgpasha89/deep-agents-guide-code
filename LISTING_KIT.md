## Before you press publish

1. **Create the GitHub repository first.** The book links to `github.com/sadiqgpasha89/deep-agents-guide-code` on the copyright page, the "About This Book" page and Appendix F. The repository must exist, with exactly that name, before the first sale.
2. **Read the book yourself and run a few code samples** from the repository (build-along 1 is a good test). The text and code were drafted with AI assistance from public documentation, and the code has been syntax-checked but not run against live packages. Fix anything you find; you can send me corrections and I will rebuild.
3. **Consider telling LangChain.** The title names their product. LangChain's brand page does not cover third-party books and gives press@langchain.dev for other questions. A short heads-up email is cheap and avoids surprises.
4. **Check tax.** Selling from India usually means GST and income-tax questions. Ask a chartered accountant before your first payout. Gumroad acts as merchant of record and collects VAT and sales tax from buyers, but that does not replace your own filings.
5. **Do a test purchase** (a 100% discount code works) and open the delivered file on your phone and laptop.

## Long description (paste into the description field)

**Deep Agents is the open-source agent harness built on LangChain and LangGraph.** The official documentation is excellent reference material, but it is a poor way to learn the subject the first time. This book teaches it in order, from first principles to production, and then trains you to explain it under questioning.

### What you get

- **12 parts, 78 chapters and 6 appendices** covering the execution environment, context management, delegation and steering, middleware, frontends, protocols (ACP, MCP, A2A, AG-UI), Managed Deep Agents, fault tolerance and OpenWiki.
- **77 figures**: architecture diagrams, flows and schematic illustrations.
- **Every feature explained the same way:** what it is, why it exists, when to use it, how it looks in code, and where it breaks.
- **A full interview section:** 124 questions in three families, each answered with a short answer, an elaborated explanation, step-by-step reasoning, advantages, limitations, trade-offs, edge cases and likely follow-ups. There are direct (recall) questions, concept (how and why) questions and scenario (diagnose and design) questions for every topic, from foundations and backends to Managed Deep Agents, OpenWiki and the capstone. Then 10 system-design walkthroughs, 14 spot-the-bug exercises, rapid-fire numbers and defaults, and four mock interview rounds.
- **Five build-along projects:** a research agent, a data analysis agent, a content builder, a retrieval-augmented agent and a capstone that uses every layer.
- **Reference appendices:** a one-page cheat sheet, the trap list, version notes, a troubleshooting catalogue and a glossary.
- **Companion code on GitHub:** every code block from the book as files, organised by chapter.

### Who it is for

- Engineers building long-running agents on LangChain and LangGraph who want a map of the terrain, with defaults and sharp edges marked.
- Candidates preparing for AI-engineering interviews.

### Good to know

- This is an **unofficial** guide. It is independent and not published, sponsored or endorsed by LangChain, Inc.
- It was written with AI assistance from the public documentation, under the author's direction.
- It describes the documentation as of **October 2026**. This framework moves quickly and several features are in beta, so check names and versions against the release you install.
- It is a PDF (A4), best read on a laptop, tablet or large phone.

## Publish on Gumroad

1. Create an account at gumroad.com and complete the payout and tax details (these are yours to enter).
2. Create a new product, choose a digital product, and paste the name, price and description above.
3. Upload the two cover images, then upload the PDF as the product file.
4. Create a second product at $0 for the free sample, and link to it from the book's description to gather readers.
5. Look in the product's content settings for options such as stamping the buyer's details on the PDF (to discourage sharing), and for a refund policy.
6. Publish, then make a test purchase with a 100% discount code.

## Publish on Leanpub

1. Create an account and a new book. Leanpub's own writing modes generate files from a manuscript. Because this book is already a finished PDF, choose the **Upload** mode, which lets you upload a PDF and/or EPUB and sell it directly. In that mode Leanpub does not generate files for you.
2. Upload `Deep_Agents_The_Complete_Guide_Unofficial.pdf`, set the minimum and suggested price, and add the description and cover.
3. Leanpub welcomes AI-assisted books made under human direction but does not allow what it calls "AI slop". Review the book, add your own judgement where you can, and use the book's AI Usage page (`leanpub.com/YOUR_BOOK/settings/ai`) to describe how AI was used.
4. Publish when the preview looks right.

If one platform rejects the book, the other is an easy fallback.
